FERIA DE CIENCIAS - SITIO WEB
================================

Este paquete recrea el sitio mostrado en el PDF enviado por el usuario.

Incluye:
- index.html
- styles.css
- script.js

INTERACTIVIDAD IMPLEMENTADA
- Navegación interna por secciones.
- Botón de cambio de tema.
- Preguntas frecuentes tipo acordeón.
- Desafío Solar con respuesta inmediata.
- Registro de fuentes con agregar/eliminar y almacenamiento local.
- Campo "¿Tienes otra pregunta?" con respuestas locales según palabras clave.
- Diseño responsive para celular y escritorio.

No necesita servidor ni base de datos para funcionar localmente.

PUBLICACIÓN GRATUITA
Puedes subir estos tres archivos a un hosting estático gratuito como GitHub Pages o Cloudflare Pages.
